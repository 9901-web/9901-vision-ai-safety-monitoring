# 비전AI 기반 현장 안전관제 프로젝트

YOLOv8과 OpenCV를 이용하여 영상 속 작업자와 차량을 탐지하고,
차량 주변에 설정한 다각형 구역의 침범 여부를 판단하는 프로젝트입니다.

안전모 착용 여부의 색상 기반 추정, 차량 이동 속도 추정,
영상 위 상태 표시 및 CSV 이벤트 기록 기능을 포함합니다.

## 1. 프로젝트 목적

- 영상 속 작업자와 차량의 위치 확인
- 차량 주변 구역에 접근한 작업자 감지
- 안전모 미착용 의심 상황 표시
- 위험 상황의 발생 시점을 CSV 파일로 기록

본 프로젝트는 영상 분석 및 안전관제 기능을 구현한 실습용 프로토타입입니다.
실제 현장 적용 성능은 별도의 검증이 필요합니다.

## 2. 주요 기능

### 사람·차량 탐지 및 추적

- YOLOv8n 모델 사용
- 사람 클래스와 차량 관련 클래스 탐지
- 추적 ID를 활용하여 차량 위치 변화 기록
- 탐지 신뢰도 기준: 0.25

기본 COCO 사전학습 모델 기준으로 사용하는 클래스는 다음과 같습니다.

| 클래스 ID | 대상 |
|---|---|
| 0 | 사람 |
| 2 | 자동차 |
| 3 | 오토바이 |
| 5 | 버스 |
| 7 | 트럭 |

지게차 전용 클래스나 별도 지게차 학습 모델은 포함되어 있지 않습니다.

### 차량 주변 구역 침범 감지

- 차량 탐지 박스의 하단 중심점을 기준으로 육각형 구역 생성
- 작업자 탐지 박스의 하단 중심점이 구역 내부 또는 경계에 있는지 확인
- 침범 시 작업자 박스를 빨간색으로 표시
- 작업자와 차량 사이에 연결선 표시

위험구역은 영상상의 픽셀 좌표로 설정됩니다.
실제 거리 단위의 안전거리나 충돌 예상 시간을 계산하지 않습니다.
차량이 정지한 상태에서도 구역 침범 경고가 발생할 수 있습니다.

### 안전모 착용 여부 추정

- 사람 탐지 박스의 상단 30% 영역 분석
- HSV 색상 공간에서 지정한 유색 및 흰색 범위 검출
- 해당 색상 비율이 기준값을 넘으면 착용으로 추정

안전모 전용 AI 모델을 사용하는 방식이 아닙니다.
머리 주변 배경, 조명, 복장 등에 따라 잘못된 판정이 발생할 수 있습니다.

### 차량 속도 추정

- 동일 추적 ID의 위치 변화와 영상 시간 차이를 사용
- 픽셀 이동량에 고정 환산 계수를 적용
- 이전 속도와 현재 속도를 가중 평균하여 표시

화면에 표시되는 km/h는 고정 계수를 이용한 추정값입니다.
카메라 원근감과 실제 거리 보정이 적용되지 않아 실측 속도를 의미하지 않습니다.

### 상태 표시

OpenCV 영상 창에 다음 내용을 표시합니다.

- SAFE / WARNING / DANGER 상태
- 현재 분석 프레임의 구역 침범 집계
- 현재 분석 프레임의 안전모 미착용 의심 인원
- 추적 ID별 차량 추정 속도
- 최근 이벤트 최대 4개

침범 집계는 사람과 차량 구역의 조합을 기준으로 증가하므로,
한 사람이 여러 차량 구역에 포함되면 중복 집계될 수 있습니다.

### 이벤트 기록

이벤트 발생 시 safety_event_log.csv에 다음 항목을 저장합니다.

- 실제 기록 시간
- 영상 내 시간
- 이벤트 종류
- 상세 내용

이벤트 종류별로 영상 시간 기준 2초를 초과하는 간격으로 기록합니다.
위험이 지속되면 같은 상황이 다시 기록될 수 있습니다.

구역 침범과 안전모 미착용 의심이 동시에 발생하면,
구역 침범 이벤트인 DANGER를 우선 기록합니다.

## 3. 사용 기술

- Python
- Ultralytics YOLOv8
- OpenCV
- NumPy
- Python 기본 모듈: os, math, csv, datetime

## 4. 파일 구성

| 파일 | 용도 |

| main.py | 영상 분석 및 화면 표시 |

| .gitignore | Git 업로드 제외 설정 |
| README.md | 프로젝트 설명 및 실행 안내 |

## 5. 설치 방법

터미널에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
python -m pip install -r requirements.txt
```

화면을 표시하는 프로그램이므로 GUI를 사용할 수 있는 PC 환경이 필요합니다.
opencv-python-headless 대신 opencv-python을 사용합니다.

패키지 버전은 아직 고정하지 않았습니다.
실제 실행에 성공한 환경의 Python 및 패키지 버전을 추가 기록해야 합니다.

## 6. 영상 및 모델 준비

### 입력 영상

프로젝트 폴더에 kimhyunsoo.mp4를 넣습니다.

다른 영상을 사용할 경우 main.py의 설정을 변경합니다.

```python
VIDEO_PATH = "다른영상.mp4"
```

원본 시연 영상은 저장소에 포함하지 않습니다.
영상이 없으면 프로그램을 실행할 수 없으므로 분석할 영상을 별도로 준비해야 합니다.

### 모델

기본 설정은 다음과 같습니다.

```python
MODEL_PATH = "yolov8n.pt"
```

Ultralytics 기본 YOLOv8n 가중치를 사용합니다.
로컬에 가중치가 없는 경우 라이브러리가 다운로드를 시도할 수 있으므로
최초 실행에는 인터넷 연결이 필요할 수 있습니다.

오프라인 환경에서는 가중치를 미리 준비하여 프로젝트 폴더에 넣습니다.

## 7. 실행 방법

현재 코드의 상대 경로는 터미널의 작업 폴더를 기준으로 해석됩니다.
main.py, 영상 및 모델을 준비한 프로젝트 폴더에서 실행합니다.

```bash
python main.py
```

실행하면 Construction Safety Monitor 창이 열립니다.

- ESC: 프로그램 종료
- 영상 끝에 도달하면 종료
- 이벤트 기록: 프로젝트 실행 폴더의 safety_event_log.csv

CSV 파일이 이미 있으면 기존 기록 뒤에 새로운 기록을 추가합니다.

현재 코드에는 분석 결과를 동영상 파일로 저장하는 기능이 없습니다.

## 8. 주요 설정값

| 설정 | 기본값 | 의미 |
|---|---|---|
| VIDEO_PATH | kimhyunsoo.mp4 | 입력 영상 경로 |
| MODEL_PATH | yolov8n.pt | 모델 가중치 경로 |
| HELMET_THRESHOLD | 0.01 | 안전모 관련 색상 비율 기준 |
| PIXEL_TO_METER | 0.05 | 속도 추정용 고정 환산 계수 |
| SPEED_THRESHOLD_KMH | 2.5 | 이 값 미만의 추정 속도를 0으로 처리 |
| MIN_PIXEL_MOVE | 3 | 미세 위치 변화 제외 기준 |
| LOG_COOLDOWN_SEC | 2.0 | 이벤트 종류별 기록 간격 기준 |

WORK_POLYGON으로 차량 주변 육각형 구역을 조정할 수 있습니다.

## 9. 현재 한계

- 지게차 및 중장비 전용 학습 모델을 사용하지 않습니다.
- 안전모 착용 여부는 색상 규칙에 기반한 추정입니다.
- 안전모 판단 시 시각화가 적용된 프레임을 사용하므로
  화면에 그린 색상이 판정에 영향을 줄 수 있습니다.
- 차량 제외 여부는 화면 위치 조건으로 결정합니다.
  PARKED 표시는 실제 정차 여부를 분석한 결과가 아닙니다.
- 위험구역 크기와 차량 제외 조건은 특정 영상에 맞춰 설정되어 있습니다.
- 속도 추정에 카메라 보정 및 원근감 보정이 적용되지 않습니다.
- 전체 프레임 중 5개당 2개를 분석하므로 짧은 위험 상황을 놓칠 수 있습니다.
- 영상 재생 속도를 원본 FPS에 맞추는 제어는 포함되어 있지 않습니다.
- 웹 대시보드, 경고음, 외부 알림, 결과 영상 저장 기능은 포함되어 있지 않습니다.
- 정량적인 탐지 성능과 처리 속도는 별도 측정이 필요합니다.
